# RAL-271 — Inventory Dashboard as a landing target

**V18-29** — plan: `docs/v1.8/Phase_Plan.md` §3.5. Depends on V18-20 ([RAL-262](https://linear.app/ralphoksiprojects/issue/RAL-262/permission-aware-landing-selector-user-form-division-config-office)).

The second of the three landing targets. The smallest of the set: no page change expected, just correct gating.

* Offered **only** when `CanAccessInventory` resolves true for that user — which means the resolved value (role bypass → division default → per-user override), not the raw override flag.
* Never offered to office users: inventory is PPDO-internal, and the portal gate already blocks it.
* If the permission is later revoked, the resolution chain (V18-16) must fall through to the next preference rather than stranding the user on a 403.

**Done when:** an Admin-division user can open the portal straight onto Inventory, a user without inventory access cannot select it, and revoking the flag on a user who had it selected lands them somewhere sensible instead of an error.
