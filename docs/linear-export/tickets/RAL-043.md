# RAL-43 — User Management — page UI + PermissionGroup assignment

Build the User Management page UI where Admins create users, assign roles/divisions, reset passwords, and manage permission overrides.

**User Management page** (`src/app/(portal)/admin/users/page.tsx`):

* Table of all users — name, email, role, division, status (active/inactive)
* "Add User" button → modal: name, email, role, division (auto-assigns PermissionGroup)
* "Reset Password" per user
* "Edit" per user — update details + permission overrides
* "Deactivate" per user (soft delete)
* Permission overrides section — toggle individual flags per user

**Reference:** `PPDO_PROJECT_CONTEXT.md` → design tokens, `PROJECT_DOCUMENTATION_NET_AZURE.md` → RBAC model
