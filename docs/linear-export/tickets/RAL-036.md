# RAL-36 — Resource Links — Resources page UI + Dashboard widget

Build the Resources page and Dashboard widget for resource links.

**Resources page** (`src/app/(portal)/resources/page.tsx`):

* Full page with all categories as collapsible sections
* Each link shows title + external link icon, opens in new tab on click
* Search box to filter links by title or category
* Admin/Staff with permission: "Add Link" button opens a modal (title, URL, category)
* Admin: edit and delete buttons per link

**Dashboard widget** (`src/components/inventory/ResourceLinksWidget.tsx`):

* Compact card on the Main Dashboard
* Shows categories as collapsible groups
* Max 5 links visible per category, "View all" → navigates to Resources page
* No add/edit/delete in widget — manage links from the full Resources page only

**Reference:** `CLAUDE.md` → Resource Links seed data (for category names), `PPDO_PROJECT_CONTEXT.md` → design tokens
