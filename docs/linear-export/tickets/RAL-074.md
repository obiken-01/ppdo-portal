# RAL-74 — UI: Funding Sources Config page

> 🌿 **Working branch: **`release/1.1.0` — all v1.1 work branches off `release/1.1.0` and PRs target `release/1.1.0` (not `main`).
>
> 🎨 **Frontend design:** read `docs/v1.1/Config_Pages_Design_Spec.md` §4 (Funding Sources Config) — the Penpot config screens were extracted into this in-repo spec so implementation does **not** need a live Penpot connection. Use the spec; opening Penpot is optional.

## Overview

Config page for Funding Sources — GF, GAD, LDRRMF, SEF, 20DF, TF — used as Source of Fund in AIP and WFP.

**Mockup**: Penpot Page 3, Screen 12 → captured in `docs/v1.1/Config_Pages_Design_Spec.md` §4 (read this instead of Penpot).

> **Seeding note:** there is no seed migration — the user will load the 6 funding sources by manually uploading `funding_sources.csv` (columns: `code, name, description, is_active`) through this page's CSV Upload feature.

## Features

1. **Data table**: Code · Name · Description (truncated) · Status badge · Actions
2. **Search**: filter by Code or Name
3. **Status filter**: All / Active / Inactive
4. **Add** → popup modal
5. **Edit** → same modal pre-filled
6. **Deactivate** → confirmation dialog → soft delete
7. **Upload / Download CSV**

### Add/Edit Modal Fields

| Field | Notes |
| -- | -- |
| Code | Required; PK — readonly on edit. e.g. `GF`, `GAD`, `LDRRMF` |
| Name | Required. e.g. "General Fund" |
| Description | Optional textarea |
| Active | Toggle |

## Route

`/config/funding-sources`
