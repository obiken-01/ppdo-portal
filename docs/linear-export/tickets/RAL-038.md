# RAL-38 — Infrastructure — JwtMiddleware + CurrentUserService + PermissionService

Implement the three Infrastructure services that all Function handlers depend on.

**JwtMiddleware** (`PPDO.Infrastructure/Services/JwtMiddleware.cs`):

* `ValidateAsync(HttpRequestData req)` → returns `ClaimsPrincipal?`
* Reads `Authorization: Bearer <token>` header
* Validates signature, issuer, audience, expiry using `JwtSettings`
* Returns null on any validation failure — never throws

**CurrentUserService** (`PPDO.Infrastructure/Services/CurrentUserService.cs`):

* Reads UserId, Role, Division from ClaimsPrincipal
* `GetCurrentUserAsync(ClaimsPrincipal)` → returns `UserDto`

**PermissionService** (`PPDO.Application/Services/PermissionService.cs`):

* `CanAccessInventoryAsync(user)`, `CanAccessReportsAsync(user)`, `CanManageUsersAsync(user)`, `CanManageResourceLinksAsync(user)` — resolves group + override logic
* SuperAdmin/Admin always returns true
* Staff/Observer: `override ?? group flag`
* Resource links write rule: Staff can add only (edit/delete always false for Staff)

**Reference:** `CLAUDE.md` → Architecture Rules (JWT pattern, permission check pattern)
