# RAL-73 — UI: Office Config page

> 🌿 **Working branch: **`release/1.1.0` — all v1.1 work branches off `release/1.1.0` and PRs target `release/1.1.0` (not `main`).
>
> 🎨 **Frontend design:** read `docs/v1.1/Config_Pages_Design_Spec.md` §3 (Office Config) — the Penpot config screens were extracted into this in-repo spec so implementation does **not** need a live Penpot connection. Use the spec; opening Penpot is optional.

## Overview

Config page for Planning Offices — the 16 PPDO offices used for office selection throughout the portal.

**Mockup**: Penpot Page 3, Screen 11 → captured in `docs/v1.1/Config_Pages_Design_Spec.md` §3 (read this instead of Penpot).

> **Seeding note:** there is no seed migration — the user will load the 16 offices by manually uploading `offices.csv` (columns: `office_code, office_name, is_active`) through this page's CSV Upload feature.

## Features

1. **Data table**: Office Code · Office Name · Status badge · Actions
2. **Search**: filter by Office Code or Office Name
3. **Status filter**: All / Active / Inactive (no type filter)
4. **Add** → popup modal
5. **Edit** → same modal pre-filled
6. **Deactivate** → confirmation dialog → soft delete
7. **Upload / Download CSV**

### Add/Edit Modal Fields

| Field | Notes |
| -- | -- |
| Office Code | Required; PK — readonly on edit. The mockup (spec §3) shows **short codes** — e.g. `PGO`, `SPO`, `PPDO`. ⚠️ The earlier "AIP ref-code format `1000-000-1-01-001`" note was superseded — confirm against `offices.csv`, then display exactly as stored. |
| Office Name | Required, e.g. "Provincial Planning and Development Office" |
| Active | Toggle |

## Route

`/config/offices`
