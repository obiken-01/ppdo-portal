# RAL-49 — Receive Delivery — DeliveryService + submit + PR status transitions

Implement DeliveryService and DeliveryFunctions for receiving deliveries against PRs.

**Key business rules:**

* Delivery Ref format: `DEL-YYYYMMDD-XXXXX` (5-digit random, Manila timezone UTC+8)
* Issue Ref format: `ISS-YYYYMMDD-XXXXX-N`
* Split delivery: one item can be split across multiple divisions — aggregate QtyIssued per division
* After submit: auto-update PR status `Open → PartiallyDelivered → FullyDelivered` based on fulfillment %

**DeliveryFunctions endpoints:** `GET /api/deliveries`, `GET /api/deliveries/{id}`, `POST /api/deliveries`

**Reference:** `PPDO_PROJECT_CONTEXT.md` → Delivery Ref format, split delivery rules, PR status transitions
