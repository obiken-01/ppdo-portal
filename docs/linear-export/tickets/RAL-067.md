# RAL-67 — DB: Budget Planning schema v2 — LDIP, AIP, WFP, Config tables

> 🌿 **Working branch:** `release/1.1.0` — all v1.1 work branches off `release/1.1.0` and PRs target `release/1.1.0` (not `main`).

## DB: Planning schema migration (v1.1)

Create EF Core migrations for all v1.1 planning tables.

**Reference:** Read `docs/v1.1/DB_Model.md` first — it is the authoritative schema.

---

### Tables to create

**Config tables** — use `is_active` for soft delete only; no `IsDeleted` column:

* `offices` — `id INT IDENTITY PK`, `office_code NVARCHAR(20) UNIQUE NOT NULL`, `office_name NVARCHAR(200) NOT NULL`, `is_active BIT NOT NULL DEFAULT 1`, `created_at/updated_at DATETIME2`
* `funding_sources` — `id INT IDENTITY PK`, `code NVARCHAR(20) UNIQUE NOT NULL`, `name NVARCHAR(100) NOT NULL`, `description NVARCHAR(MAX) NULL`, `is_active BIT NOT NULL DEFAULT 1`, `created_at/updated_at DATETIME2`
* `accounts` — `id INT IDENTITY PK`, `account_title NVARCHAR(300) NOT NULL`, `account_number NVARCHAR(20) UNIQUE NOT NULL`, `normal_balance NVARCHAR(10) NULL`, `description NVARCHAR(MAX) NULL`, `is_active BIT NOT NULL DEFAULT 1`, `created_at/updated_at DATETIME2`
  * **No** `account_type` **or** `display` **columns** — expenditure type (PS/MOOE/CO) is derived from `account_number` prefix at query time, not stored

**LDIP:**

* `ldip_records` — `id, ref_code, title, fiscal_year_start, fiscal_year_end, entry_mode, status DEFAULT 'Draft', source_id FK self (nullable), created_by FK users, created_at, updated_at`

**AIP — 4 SEPARATE tables, NOT a single self-referencing table:**

* `aip_records` — top-level record: `id, fiscal_year, entry_source, original_filename (null), uploaded_by FK users, uploaded_at, status DEFAULT 'Draft', ldip_id FK ldip_records (null), source_id FK self (null)`
* `aip_offices` (level 1, 5-segment ref code) — `id, aip_record_id FK aip_records, ref_code, name, sector`, UNIQUE(aip_record_id, ref_code)
* `aip_programs` (level 2, 6-segment) — `id, office_id FK aip_offices, ref_code, name`, UNIQUE(office_id, ref_code)
* `aip_projects` (level 3, 7-segment) — `id, program_id FK aip_programs, ref_code, name`, UNIQUE(program_id, ref_code)
* `aip_activities` (level 4, 8-segment) — `id, project_id FK aip_projects, ref_code, name, esre_code, implementing_office, start_date NVARCHAR(50), end_date NVARCHAR(50), expected_outputs NVARCHAR(MAX), funding_source_id FK funding_sources (null), funding_source_snapshot NVARCHAR(20) (null), ps/mooe/co/total/cc_adaptation/cc_mitigation DECIMAL(18,2), cc_typology_code NVARCHAR(50)`, UNIQUE(project_id, ref_code)

**WFP:**

* `wfp_records` — `id, aip_record_id FK aip_records, office_id FK offices, fiscal_year, status DEFAULT 'Draft', created_by FK users, created_at, updated_at, finalized_at (null), source_id FK self (null)`, UNIQUE(aip_record_id, office_id)
* `wfp_activities` — `id, wfp_id FK wfp_records, aip_activity_id FK aip_activities`, UNIQUE(wfp_id, aip_activity_id)
* `wfp_expenditure_lines` — `id, wfp_activity_id FK wfp_activities, expenditure_type NVARCHAR(10), resources_needed, responsible_unit, success_indicator, means_of_verification, account_id FK accounts (null), account_number_snapshot NVARCHAR(20), account_title_snapshot NVARCHAR(300), total_appropriation DECIMAL(18,2), apply_reserve BIT DEFAULT 0, reserve_amount DECIMAL(18,2), net_appropriation DECIMAL(18,2), q1/q2/q3/q4/quarterly_total DECIMAL(18,2), funding_source_id FK funding_sources (null), funding_source_snapshot NVARCHAR(20), sort_order INT DEFAULT 0`

**Audit:**

* `audit_log` — `id BIGINT IDENTITY PK, table_name NVARCHAR(100), record_id INT, action NVARCHAR(10), changed_by FK users, changed_at DATETIME2, old_values NVARCHAR(MAX), new_values NVARCHAR(MAX)`

**Indexes:** create all indexes listed in DB_Model.md section 7.

---

### Seed data — NO seed migration

> **Decision (2026-06-10):** Seed data is loaded **manually by the user through each config page's CSV Upload feature** — do NOT create an EF seed migration. The seed files (`chart_of_accounts.csv`, `offices.csv`, `funding_sources.csv`) stay outside the repo and will be uploaded via the Config UI ([RAL-72](<https://linear.app/ralphoksiprojects/issue/RAL-72/ui-account-config-page>)/73/74) once the CSV upload endpoints ([RAL-70](<https://linear.app/ralphoksiprojects/issue/RAL-70/api-config-crud-endpoints-csv-uploaddownload>)) are live.
