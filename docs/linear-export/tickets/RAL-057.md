# RAL-57 — Item Ledger + PR Register — page UIs

Build Item Ledger and PR Register page UIs — both are read-only list views.

**Item Ledger page** (`src/app/(portal)/inventory/item-ledger/page.tsx`):

* Table per item: StockNo, Description, Unit, Total Ordered, Total Delivered, Total Distributed, Remaining Stock, Status (In Stock / Low / Out of Stock)
* Color-coded status badges

**PR Register page** (`src/app/(portal)/inventory/pr-register/page.tsx`):

* Full PR list with status filter tabs (All, Open, Partially Delivered, Fully Delivered, Completed)
* Columns: PR No, Date, Division, Requested By, Total Amount, Status badge, Fulfillment %, View Report action
* TanStack Table with sorting and filtering
