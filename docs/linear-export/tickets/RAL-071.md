# RAL-71 — UI: Config Dashboard

> 🌿 **Working branch: **`release/1.1.0` — all v1.1 work branches off `release/1.1.0` and PRs target `release/1.1.0` (not `main`).
>
> 🎨 **Frontend design:** read `docs/v1.1/Config_Pages_Design_Spec.md` §5 (Config Dashboard) and §1 (Sidebar — Configuration group) — the Penpot config screens were extracted into this in-repo spec so implementation does **not** need a live Penpot connection. Use the spec; opening Penpot is optional.

## Overview

Landing page for the Configuration section. Shows stat tiles for each config type with live record counts.

**Mockup**: Penpot Page 3, Screen 09 → captured in `docs/v1.1/Config_Pages_Design_Spec.md` §5 (read this instead of Penpot).

> **Note (**[RAL-72](https://linear.app/ralphoksiprojects/issue/RAL-72/ui-account-config-page) **groundwork): **[RAL-72](https://linear.app/ralphoksiprojects/issue/RAL-72/ui-account-config-page) shipped an interim `/config → /config/accounts` redirect (`frontend/src/app/(portal)/config/page.tsx`). **This ticket replaces that redirect** with the dashboard below. The live `Sidebar.tsx` currently links **Configuration → /config** as a single item; expand it to the sub-nav per spec §1.

## Layout

Three tiles in a row (counts from spec §5: Accounts 143 · Offices 16 · Funding Sources 6):

| Tile | Count Source ([RAL-70](https://linear.app/ralphoksiprojects/issue/RAL-70/api-config-crud-endpoints-csv-uploaddownload) API — enveloped `{ data, error, message }`; count = `data.length`) | Link |
| -- | -- | -- |
| Accounts | `GET /api/config/accounts?``active``=true` | `/config/accounts` |
| Offices | `GET /api/config/offices?``active``=true` | `/config/offices` |
| Funding Sources | `GET /api/config/funding-sources?``active``=true` | `/config/funding-sources` |

Each tile: icon · config type name · caption · active record count · "Manage →" button (per spec §5).

## Portal Nav

The sidebar Configuration item expands to show sub-links (Dashboard, Accounts, Offices, Funding Sources) per spec §1, with the active-nav highlight the sidebar already uses for other groups (e.g. Inventory).

## Route

`/config`
