# RAL-25 — Scaffold Next.js 14 frontend with Tailwind + shadcn/ui + design tokens

Scaffold the Next.js 14 frontend project with all base dependencies configured.

**Steps:**

```bash
cd frontend
npx create-next-app@latest . --typescript --tailwind --eslint --app --src-dir
npx shadcn@latest init
```

**Configure** `tailwind.config.ts` with PPDO design tokens from `PPDO_PROJECT_CONTEXT.md` Section 8 (green palette, slate, amber, danger, info colors).

**Install additional dependencies:**

```bash
npm install @tanstack/react-table axios react-hook-form zod @hookform/resolvers
npm install @fullcalendar/react @fullcalendar/daygrid @fullcalendar/timegrid
```

**Create base file structure:**

* `src/app/(public)/` — landing, login pages
* `src/app/(portal)/` — authenticated pages with layout
* `src/lib/api.ts` — Axios instance placeholder
* `src/lib/auth.ts` — token storage placeholder
* `src/types/` — shared TypeScript interfaces

**Reference:** `PROJECT_DOCUMENTATION_NET_AZURE.md` → Section 4 (Project Structure)
**Conventions:** `NAMING_CONVENTIONS.md` → JavaScript/TypeScript/React section
