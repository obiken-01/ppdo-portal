# RAL-40 — User Management — CRUD endpoints + UserService + RBAC enforcement

Implement UserService and UserFunctions for user management + PermissionGroup assignment.

**UserService methods:** `GetAllAsync`, `GetByIdAsync`, `CreateAsync` (assigns PermissionGroup by division), `UpdateAsync`, `ResetPasswordAsync`, `DeactivateAsync`, `UpdatePermissionOverridesAsync`

**UserFunctions endpoints:** all `/api/users` endpoints + `PUT /api/users/{id}/permissions`

**RBAC enforcement:**

* Admin can manage Staff + Observer only
* SuperAdmin can manage everyone
* Staff with CanManageUsers can manage Staff + Observer only

**Reference:** `PROJECT_DOCUMENTATION_NET_AZURE.md` → Users API endpoints, RBAC rules
