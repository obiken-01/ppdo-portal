# RAL-48 — Create PR — PurchaseRequestService + submit + PR number generation + Excel import

Implement PurchaseRequestService and PurchaseRequestFunctions for PR submission and management.

**Key business rules (from PPDO_PROJECT_CONTEXT.md):**

* PR No. format: `101-1041-GF-YYYY-MM-DD-XXX` (3-digit zero-padded sequence per day)
* New StockNos not in Items Master → auto-create with `IsNewItem = true`
* Status starts as `Open` on creation
* Division scope: Staff can only create PRs for their own division

**PurchaseRequestFunctions endpoints:** all `/api/purchase-requests` endpoints + `/api/purchase-requests/template` (download) + `/api/purchase-requests/import` (upload)
