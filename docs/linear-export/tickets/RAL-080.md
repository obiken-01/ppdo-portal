## Overview

Landing page for the Budget Planning section — answers "where does this fiscal year's budget planning stand?" The sidebar's "Budget Planning › Dashboard" sub-link points here.

**Mockup**: Penpot Page 4, Screen 20 (PPDO view) + Screen 21 (Visitor view) → captured in `docs/v1.1/Budget_Planning_Pages_Design_Spec.md` §8–§9 (read this instead of Penpot).

**Access rule (decided 2026-06-10): PPDO users manage all offices** (full view + edit on any office's records). Non-PPDO (Visitor) users are restricted to their own office.

`/budget-planning` (or `/budget-planning/dashboard`)

## Layout

### Header controls

* **Fiscal Year selector** — defaults to latest AIP fiscal year
* **Office selector** — defaults to user's office; PPDO users get an "All Offices" option; Visitors locked to their own office
* **No** Upload AIP / New LDIP buttons (creation happens on the respective pages)
* **No** budget amounts anywhere on the dashboard

### Navigation buttons

Three buttons: **LDIP · AIP · WFP** → navigate to the respective pages (office-scoped per the selectors).

### Counters row (PPDO users only)

| Tile | Content |
| -- | -- |
| LDIP records | total + breakdown (final / draft / archived) |
| AIP records | total + per-FY status line |
| WFPs (selected FY) | X of N offices final + progress bar |

### WFP status by office (PPDO users only)

Table: Office · Status badge (Final / Draft / Not started) · Open action. **No appropriation amounts.** "Not started" = active office in `offices` config with no `wfp_records` row for the selected AIP. Sorted: Not started → Draft → Final. Open action goes to `/budget-planning/wfp?aipId=&officeId=` (PPDO has full manage access).

### Recent activity

From `audit_log` ([RAL-77](<https://linear.app/ralphoksiprojects/issue/RAL-77/api-audit-logging-for-budget-planning-config-records>)): who changed what, when. **PPDO sees all offices' activity; Visitors see only their own office's.** Latest \~10 entries.

## Role Visibility Matrix

| Section | PPDO | Visitor |
| -- | -- | -- |
| FY + Office selectors | all offices + "All Offices" | locked to own office |
| LDIP / AIP / WFP buttons | ✓ | ✓ (pages open office-scoped) |
| Counters row | ✓ | hidden |
| WFP status by office table | ✓ (all 16) | hidden |
| Recent activity | all offices | own office only |

## Acceptance Criteria

- [ ] FY selector defaults to latest AIP fiscal year; office selector defaults to user's office
- [ ] Visitor cannot change the office selector; counters + office table not rendered for Visitors
- [ ] WFP status table shows every active office with correct Final/Draft/Not started status; no amounts
- [ ] Open action navigates to the WFP page with aipId + officeId preselected
- [ ] Recent activity scoped per role
- [ ] No budget amounts rendered anywhere on the dashboard
