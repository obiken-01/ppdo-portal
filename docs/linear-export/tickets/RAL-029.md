# RAL-29 — Configure Azure Functions Program.cs — DI, JWT, EF Core

Configure Azure Functions host in `PPDO.Functions/Program.cs` — DI registration, JWT middleware, EF Core, logging.

**DI registrations needed:**

* `AppDbContext` — scoped, connection string from `SqlConnectionString` app setting
* `IJwtMiddleware` → `JwtMiddleware` — singleton
* `IPermissionService` → `PermissionService` — scoped
* `ICurrentUserService` → `CurrentUserService` — scoped
* All Application services (to be added as implemented)
* `IExcelService` → `ExcelService` — scoped
* Application Insights — `builder.Services.AddApplicationInsightsTelemetryWorkerService()`

**JWT configuration:**

* Bind `JwtSettings` from `Jwt__*` app settings using Options pattern
* Read from `local.settings.json` locally, Azure App Settings in production

**Create** `local.settings.json` (not committed — git-ignored):

```json
{
  "IsEncrypted": false,
  "Values": {
    "AzureWebJobsStorage": "UseDevelopmentStorage=true",
    "FUNCTIONS_WORKER_RUNTIME": "dotnet-isolated",
    "SqlConnectionString": "Server=.\\SQLEXPRESS;Database=PPDOPortalDev;Trusted_Connection=True;TrustServerCertificate=True;",
    "Jwt__SecretKey": "dev-secret-key-minimum-32-characters-long",
    "Jwt__Issuer": "http://localhost:4280",
    "Jwt__Audience": "ppdo-portal",
    "Jwt__AccessTokenExpiryMinutes": "15",
    "Jwt__RefreshTokenExpiryDays": "7",
    "APPLICATIONINSIGHTS_CONNECTION_STRING": ""
  }
}
```

**Create** `local.settings.json.example` and `frontend/.env.example` (both committed — safe templates).

**Reference:** `CLAUDE.md` → Local Configuration Files, Architecture Rules
