# RAL-42 — Login page UI + Axios client + auth guard (Penpot 02 Login)

Build the login page UI matching the Penpot `02 Login` frame. Set up the Axios client, auth token storage, and route protection.

**Login page** (`src/app/(public)/login/page.tsx`):

* Email + password form using React Hook Form + Zod
* Calls `POST /api/auth/login` via Axios
* On success: stores access token in memory, refresh token in httpOnly cookie, redirects to `/dashboard`
* On failure: shows error message

**Axios client** (`src/lib/api.ts`):

* Base URL from `NEXT_PUBLIC_API_BASE_URL`
* Request interceptor: attaches `Authorization: Bearer <token>`
* Response interceptor: on 401, calls `/api/auth/refresh`, retries original request; if refresh fails, redirects to `/login`

**Auth guard** (`src/app/(portal)/layout.tsx`):

* Checks for valid token on mount
* Redirects to `/login` if not authenticated

**Reference:** `PPDO_PROJECT_CONTEXT.md` → Penpot `02 Login` frame, design tokens
