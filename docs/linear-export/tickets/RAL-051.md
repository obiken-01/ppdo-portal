# RAL-51 — Inventory Dashboard stats + Item Ledger + PR Register endpoints

Implement Inventory Dashboard stats + alerts endpoints, Item Ledger, and PR Register endpoints.

**Inventory Dashboard (**`GET /api/dashboard/stats`**):**

* Group 1 — PR counts: Total, Open, Partially Delivered, Completed
* Group 2 — Stock alerts: In Stock, Low/Out of Stock, Total PR Value, Unique Items

**Item Ledger (**`GET /api/items/ledger`**):**

* Running stock totals per item across all PRs (ordered - delivered - distributed = remaining)

**PR Register (**`GET /api/purchase-requests`**):**

* Full list with status filters (Open, Partially Delivered, Fully Delivered, Completed)
* Division scoped for Staff/Observer

**Reference:** `PROJECT_DOCUMENTATION_NET_AZURE.md` → Dashboard + Items API, `PPDO_PROJECT_CONTEXT.md` → Inventory Dashboard stat card groups
