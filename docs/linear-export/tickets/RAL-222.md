# RAL-222 — RowActions shared component — hover/active/focus states, portal-wide rollout

Documentation-only ticket, filed retroactively — this work already shipped in v1.7.1 without a ticket (done ad hoc during a RowActions design pass) and is being recorded here for the milestone's history.

## What shipped

New shared `frontend/src/components/ui/RowActions.tsx` component — standardized action-button cluster for table row actions, replacing four hand-rolled action styles that had drifted across Items Master, PR List, Resource Links, and LDIP (bare icons, bordered chips, and underlined text links all doing the same job differently).

* Fixed-width buttons (default 80px, configurable per page) — every button in a row renders at the same width, not stretched or shrunk to its own text.
* Four variants: `default`, `primary`, `warn`, `danger`, each with hover, active-press (`scale-95` + darker fill), and keyboard focus-visible ring states.
* Rolled out across 12 pages: admin/users, announcements, budget-planning (AIP, LDIP), config (accounts, divisions, funding-sources, offices, price-index, procurement-presets), inventory (items-master, pr-register), resource-links.
* `docs/DESIGN_SYSTEM.md` updated with the RowActions pattern and adoption count.

## Bug fixed along the way

`danger-200`/`danger-300` are not defined Tailwind tokens in `tailwind.config.ts` (only `danger-500` and `danger-100` exist) — an early version of the danger variant's `active:` state was a silent no-op, and its `hover:` state was accidentally *lighter* than the resting background (an opacity dilution of `danger-100`, working backwards). Fixed with opacity-scaled `danger-500` instead, matching the existing `border-danger-500/30` pattern.
