# RAL-35 — Resource Links — API endpoints + ResourceLinkService

Implement `ResourceLinkService` in PPDO.Application and `ResourceLinkFunctions` HTTP endpoints in PPDO.Functions.

**Service methods:**

* `GetAllGroupedAsync()` — returns links grouped by category, active only, ordered by CategoryOrder then LinkOrder
* `CreateAsync(dto, userId)` — creates link; checks CanManageResourceLinks flag; sets IsAdminCreated based on role
* `UpdateAsync(id, dto, userId)` — Admin/SuperAdmin only
* `DeleteAsync(id, userId)` — soft delete; Admin/SuperAdmin only

**Permission enforcement:**

* Staff with CanManageResourceLinks = true → can call CreateAsync only
* Staff calling UpdateAsync or DeleteAsync → 403 Forbidden
* Observer → 403 on all write operations

**Reference:** `PROJECT_DOCUMENTATION_NET_AZURE.md` → Resource Links API endpoints, `CLAUDE.md` → CanManageResourceLinks permission logic
