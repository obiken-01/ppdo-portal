# RAL-46 — ExcelService — GeneratePRTemplate, ExportPRReport, ParsePRImport (ClosedXML)

Implement ExcelService in PPDO.Infrastructure with three methods using ClosedXML. This service is used by both the PR Report export and the Excel import feature.

**Methods:**

* `GeneratePRTemplate()` — returns `.xlsx` byte array with Section 1 header fields + Section 2 items grid. Yellow cells = user fills in, gray = locked. Includes Instructions sheet.
* `ExportPRReport(prId)` — returns `.xlsx` byte array for the PR Report — Section 1 (header), Section 2 (line items), Section 3 (distribution)
* `ParsePRImport(stream)` — reads uploaded `.xlsx`, one sheet per PR, returns `List<CreatePRDto>`. Validates required fields, flags unknown StockNos as IsNewItem, collects parse errors.

**Reference:** `PROJECT_DOCUMENTATION_NET_AZURE.md` → ExcelService design notes, `PPDO_PROJECT_CONTEXT.md` → PR Report layout
