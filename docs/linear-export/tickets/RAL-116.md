# RAL-116 — WFP Rework — Epic (v1.4)

> 🌿 **Working branch: **`release/1.4.0` (branched off `main` now that v1.3.0 is merged — PR #104). All v1.4 work branches off `release/1.4.0`; PRs target it, **not **`main`.

## Overview

Rebuilds WFP entry around the new WFP form (`WFP-NEW.xlsx`, analyzed 2026-07-06/07): expenditures are built from account + frequency + amounts, with **procurement** entries computed bottom-up from **line items** (name × qty × price, reusable as presets) instead of estimated, and **non-procurement** entries typed per frequency period. The system rolls periods up to Q1–Q4/Net/Total, enforces the 10% reserve rule, and monitors AIP budget + division allocation ceilings live. Divisions remain the data-entry scope; the report is generated per **office**.
