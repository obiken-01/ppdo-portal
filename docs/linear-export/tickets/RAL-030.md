# RAL-30 — Set up GitHub repository + GitHub Actions CI/CD pipeline

Set up GitHub Actions CI/CD workflows.

**Workflow 1 — CI (**`.github/workflows/ci.yml`**):**
Triggers on every PR to `main`:

* Backend: `dotnet restore` → `dotnet build` → `dotnet test`
* Frontend: `npm ci` → `npm run build` → `npm run lint`

**Workflow 2 — Deploy (**`.github/workflows/deploy.yml`**):**
Triggers on push to `main` — deploys Functions project to Azure.
Note: Azure SWA auto-generates its own deploy workflow when linked to GitHub — the manual deploy.yml covers the Functions deployment.

**Reference:** `PROJECT_DOCUMENTATION_NET_AZURE.md` → Section 8 (CI/CD Pipeline)
**Conventions:** `GIT_CONVENTIONS.md`
