## Description

Build the AIP FY2027 **manual **entry form (`aip_records.entry_source = 'Manual'`). The AIP hierarchy is 4 levels: **Office (L1) → Program (L2) → Project (L3) → Activity (L4)**, each mapping to an additional segment in the AIP reference code.

## ⚠️ Blocking schema gap — coordinate with [RAL-108](<https://linear.app/ralphoksiprojects/issue/RAL-108/aip-import-capture-line-item-detail-at-programproject-level-currently>)

Per `docs/v1.1/DB_Model.md`, `aip_programs` **and **`aip_projects` **store only **`ref_code` **+ **`name`**.** All line-item detail (PS/MOOE/CO, eSRE, funding source, implementing office, schedule, expected outputs, CC) lives **only on **`aip_activities` **(leaf)**. So the form cannot persist program/project-level detail today — the **exact gap **[RAL-108](<https://linear.app/ralphoksiprojects/issue/RAL-108/aip-import-capture-line-item-detail-at-programproject-level-currently>) tracks for import. Resolve [RAL-108](https://linear.app/ralphoksiprojects/issue/RAL-108/aip-import-capture-line-item-detail-at-programproject-level-currently)'s model decision first — **extend **`AipProgram`**/**`AipProject` with the line-item columns, **or normalize** program/project detail into a **synthetic leaf activity** — then this form follows the same approach.

## 🔄 Alignment notes (2026-07-01, still current)

* **Terminology fix:** Level 3 is **"Project"**, not "Sub-Program" (matches `aip_projects`). Levels = Office / Program / Project / Activity → 5 / 6 / 7 / 8 ref-code segments.
* **Status workflow = Draft / Final / Archived**; ribbon action is **Finalize** (not "Submit"); admin unlock reverts.
* **Funding Source = FK to **`funding_sources` config (store code snapshot). **eSRE code is an enum** (SS / ES / ID / EN), not free text (`aip_activities.esre_code`).
* **Money:** shared `MoneyInput`; amounts entered/stored **in thousands** → ×1000 for peso display/validation.
* `aip_activities.start_date` / `end_date` are **month-name strings** ("January"), not dates.
* Reuse shared UI; flat design; gate on `CanAccessBudgetPlanning` (+ office scope). Manual entry is available to office users; `.xlsm` **upload** stays PPDO-only (`CanUploadAip`).

| Field | Type | Fill |

## Business Rules

* Level determines segment count (5=office, 6=program, 7=project, 8=activity)
* Program/project-level detail persistence depends on the [RAL-108](https://linear.app/ralphoksiprojects/issue/RAL-108/aip-import-capture-line-item-detail-at-programproject-level-currently) decision (see above)
* Office rows carry budget subtotals (Σ of children)
* PPA Name required for program/project/activity levels
* Total = PS + MOOE + CO (auto)
