## Feature Summary

### Page (`/budget-planning/wfp`)

URL pattern: `/budget-planning/wfp?aipId=5&officeId=3` (query params — static-export safe, no `[id]` segment).

**Header:** AIP selector · Office selector · Draft/Final badge · Finalize button

**Activity grid:** Full AIP hierarchy — Sector → Office → Program → Project → Activity.
Row colors: Office = light gray · Program = light blue · Project = light green · Activity = white (fund-source coloring deferred).
Activity rows show aggregated PS / MOOE / CO / Total / Q1–Q4 from draft expenditure lines + an **Edit** button.

**Footer (sticky):** Unsaved indicator + **Save** button (always visible).

### Expenditure Popup (per Activity)

Modal size `xl`. Three tabs: **PS · MOOE · CO**.

Per-tab editable table of expenditure lines. Columns:
ACCT CODE · OBJECT OF EXPENDITURE · TOTAL APPROP · RESERVE (checkbox → 10%) · NET TOTAL · Q1 · Q2 · Q3 · Q4 · LINE TOTAL · SOURCE

* Account selector filters to the current tab's type (PS tab → 5-01- accounts, MOOE → 5-02-, CO → 5-03-)
* Reserve checkbox: net = total × 0.9; 10% Reserve column always visible
* LINE TOTAL = Q1+Q2+Q3+Q4 (auto-computed); warn if LINE TOTAL > NET TOTAL
* Source of Fund: dropdown from funding_sources config

### Save / localStorage Draft

* Draft state: `Record<aipActivityId, SaveWfpLine[]>` — updated each time popup closes
* Auto-persisted to `localStorage` key `wfp_draft_{aipId}_{officeId}` on every change
* On page load: if localStorage draft is newer than server WFP, show "Restore draft?" banner
* Save button: POST to server (activities with ≥1 line only); clears localStorage on success

### Finalize

`POST /api/budget-planning/wfp/{id}/finalize` → status Draft → Final. Final WFPs are read-only (no Edit buttons, Save disabled). Users with `canManageConfig` can Unlock.

## API Endpoints (all exist)

| Endpoint | Purpose |
| -- | -- |
| `GET /api/budget-planning/aip` | AIP selector list |
| `GET /api/budget-planning/aip/{id}` | Full AIP hierarchy (offices → programs → projects → activities) |
| `GET /api/budget-planning/wfp?aipRecordId=&officeId=` | Find existing WFP |
| `GET /api/budget-planning/wfp/{id}` | WFP detail with activities + lines |
| `POST /api/budget-planning/wfp` | Save/upsert |
| `POST /api/budget-planning/wfp/{id}/finalize` | Finalize |
| `POST /api/budget-planning/wfp/{id}/unlock` | Unlock (admin) |
| `GET /api/config/offices?active=true` | Office selector |
| `GET /api/config/accounts?active=true` | Account dropdown in popup |
| `GET /api/config/funding-sources?active=true` | Fund-source dropdown |

All use `{ data, error, message }` envelope — same `unwrap()` pattern as `lib/aip.ts`.
