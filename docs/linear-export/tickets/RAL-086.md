# RAL-86 — Admin portal: Announcements management page (TipTap rich text editor)

## Context

Part of v1.1.1 — Public Announcements feature. [RAL-83](https://linear.app/ralphoksiprojects/issue/RAL-83/db-api-announcements-entity-crud-html-sanitization) built the API. This ticket builds the portal admin UI for creating and managing announcements, including a TipTap rich text editor.

See full spec: `docs/v1.1.1/v1.1.1_Requirements.md` §3C.

> 🌿 **Working branch:** create feature branch off `hotfix/1.1.1` — PR targets `hotfix/1.1.1`
> **Blocked by: **[RAL-83](https://linear.app/ralphoksiprojects/issue/RAL-83/db-api-announcements-entity-crud-html-sanitization) (announcements API must be live)

## Scope

### Install NPM packages

```
npm install @tiptap/react @tiptap/starter-kit @tiptap/extension-text-style @tiptap/extension-color @tiptap/extension-font-family @tiptap/extension-underline dompurify
npm install --save-dev @types/dompurify
```

### New portal page: `src/app/(portal)/announcements/page.tsx`

* Auth guard via portal layout (inherited)
* Fetch `GET /api/announcements/manage` on mount
* DataTable columns:
  * **Title** (sortable)
  * **Status** badge: Draft (slate) · Published (green) · Archived (slate/dim)
  * **Published Date** (date only; "—" if Draft)
  * **Last Updated** (date)
  * **Actions**: Edit · Publish/Unpublish toggle · Archive · Delete
* Top-right: "New Announcement" (primary button, opens editor modal in create mode)
* Delete: opens `ConfirmDialog` (danger variant) — blocked if Published (show error toast instead)
* Archive: opens `ConfirmDialog` (warning variant)
* Publish / Unpublish: single-click with Toast confirmation (no confirm dialog needed)
* Toast feedback (success/error) for all actions via `useToast()`

### New component: `src/components/announcements/AnnouncementEditorModal.tsx`

* Wraps the existing `Modal` component from `components/ui/`
* Title bar: "New Announcement" or "Edit Announcement"
* **Title field**: plain text input (max 200 chars), required
* **Rich text area**: TipTap `EditorContent`

**TipTap Toolbar** (build a `RichTextToolbar.tsx` sub-component):

* Bold · Italic · Underline
* H2 · H3 (heading toggles)
* Bullet list · Ordered list
* Text color picker (uses `@tiptap/extension-color`)
* Font family dropdown (at minimum: Arial, Georgia, Courier New, Times New Roman)
* Clear formatting button (⌧)

**Modal footer:**

* "Save as Draft" (secondary button) — creates/updates as Draft
* "Publish Now" (primary button) — creates/updates AND immediately publishes
* In edit mode: shows current status badge near footer

### Sidebar change (`Sidebar.tsx`)

ADD Announcements nav item:

* Icon: megaphone (use Lucide `Megaphone` icon)
* Label: "Announcements"
* Route: `/announcements`
* Visibility: `isAdmin` (role is Admin or SuperAdmin) — same condition as `showManageUsers` minus the CanManageUsers flag check
* Position: between Dashboard and Inventory in the menu

### New files

* `src/lib/announcements.ts` — Axios helpers:

  ```ts
  getAnnouncementsManage(): Promise<Announcement[]>
  createAnnouncement(dto: CreateAnnouncementRequest): Promise<Announcement>
  updateAnnouncement(id: string, dto: UpdateAnnouncementRequest): Promise<Announcement>
  publishAnnouncement(id: string): Promise<Announcement>
  unpublishAnnouncement(id: string): Promise<Announcement>
  archiveAnnouncement(id: string): Promise<Announcement>
  deleteAnnouncement(id: string): Promise<void>
  ```
* `src/types/announcements.ts` — TypeScript interfaces:

  ```ts
  Announcement { id, title, content, status, publishedAt, createdAt, updatedAt, createdByName }
  CreateAnnouncementRequest { title, content }
  UpdateAnnouncementRequest { title, content }
  ```
