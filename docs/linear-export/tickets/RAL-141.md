# RAL-141 — WFP entry: Project/Activity selectors show only last ref-code segment; full ref code in expenditure header

> 🌿 Working branch: `release/1.4.2` (off `main`). PR targets `release/1.4.2`. Child of epic [RAL-116](https://linear.app/ralphoksiprojects/issue/RAL-116/wfp-rework-epic-v14).
> 📌 Frontend-only, small. See Ralph's screenshot on the parent conversation.

## Why

The Project and Activity `Lookup` fields show the full AIP ref code, which is long and repetitive (every activity under a project shares almost the whole prefix). Showing only the **last segment** makes the selectors far more readable, while the full ref code is shown once in the expenditure section header for context.

## Examples

* Project `1000-000-1-01-010-006-001 — Formulation/Updating of Development Plans…` → display `001 — Formulation/Updating of Development Plans…`
* Activity `1000-000-1-01-010-006-001-001 — Conduct of meetings and coordination activities` → display `001 — Conduct of meetings and coordination activities`
* Expenditure header (currently `Expenditures — {selectedActivity?.name}`) → show the **full** activity ref code: `Expenditures — 1000-000-1-01-010-006-001-001 — Conduct of meetings and coordination activities`

## Scope

`frontend/src/app/(portal)/budget-planning/wfp/entry/page.tsx`:

1. Project `Lookup` (~line 1262-1280): `getLabel` and `renderOption` currently use the full `p.refCode`. Show only the last dash-segment (`p.refCode.split("-").pop()`). Keep the full refCode in `getSearchText` so search by full code still works.
2. Activity `Lookup` (~line 1286-1299): same treatment on `a.refCode`.
3. (Optional) apply the same to the Program selector or leave it full — confirm; Program is the top level so its code is shorter/more meaningful. Default: leave Program as-is unless Ralph wants it trimmed too.
4. Expenditure header (~line 1381): change `Expenditures — {selectedActivity?.name}` to include the full activity ref code + name.

## Out of scope

The report page's ref-code rendering (already handled in [RAL-132](https://linear.app/ralphoksiprojects/issue/RAL-132/budget-planning-add-report-page-wfp-preview-prelude-to-full-report)).
