# RAL-47 — Items Master — ItemService + CRUD endpoints + lookup

Implement ItemService and ItemFunctions for Items Master CRUD + stock lookup.

**ItemService methods:** `GetAllAsync`, `GetByIdAsync`, `CreateAsync`, `UpdateAsync`, `LookupAsync(query)` — searches by StockNo or Description for Create PR autocomplete

**ItemFunctions endpoints:** `/api/items/master` CRUD + `/api/items/lookup`

**Business rules:**

* New items auto-flagged `IsNewItem = true` when created via PR submit (not directly via Items Master)
* `LookupAsync` returns StockNo, Description, Unit, UnitCost — used for bidirectional autocomplete in Create PR

**Reference:** `PROJECT_DOCUMENTATION_NET_AZURE.md` → Items API endpoints, `PPDO_PROJECT_CONTEXT.md` → bidirectional lookup rule
