# RAL-72 — UI: Account Config page

> 🌿 **Working branch:** `release/1.1.0` — all v1.1 work branches off `release/1.1.0` and PRs target `release/1.1.0` (not `main`).

## UI: Account Config page

Build the Account Config page at `/config/accounts`.

**Reference:** Read `docs/v1.1/AIP_WFP_Import_Findings.md` and `docs/v1.1/UI_Component_Standards.md`.

**Mockup:** Penpot Page 3, Screen 10

> **Seeding note:** there is no seed migration — the user will load the initial 143 accounts by manually uploading `chart_of_accounts.csv` through this page's CSV Upload feature. The upload/preview flow is the seeding path.

---

### Config page pattern

Same reusable pattern as Offices and Funding Sources:

1. Searchable/sortable data table with Active/Inactive badge
2. Add → modal form; Edit → same modal pre-filled
3. Upload CSV — upsert by `account_number`; preview step (new/updated/skipped counts) before confirming
4. Download CSV — export current records
5. Deactivate — soft delete only; confirmation dialog

---

### Data table columns

`Account Number · Account Title · Normal Balance · Status · Actions`

* **Status**: Active / Inactive badge
* **Actions**: Edit · Deactivate

No "Account Type" badge column. No "Display Label" column. These are not stored fields.

---

### Filter bar

* **Search**: text input — filters on `account_number` and `account_title`
* **Type dropdown**: All · PS · MOOE · CO
  * This is a **derived filter** — `account_type` is NOT a stored column
  * Type is inferred from `account_number` prefix:
    * PS → `account_number LIKE '5-01-%'`
    * MOOE → `account_number LIKE '5-02-%'`
    * CO → `account_number LIKE '5-03-%'`
  * Frontend passes `accountType=PS|MOOE|CO` to the API; API translates to prefix filter
* **Status toggle**: Active / Inactive / All

---

### Add / Edit modal fields

1. Account Title (required, text input)
2. Account Number (required, text input, must be unique — validate on blur)
3. Normal Balance (optional, text input — e.g. "Debit" or "Credit")
4. Description (optional, textarea)

**No "Display Label" field. No "Account Type" select field.** These do not exist in the `accounts` table.

---

### CSV download column order

`account_title, account_number, normal_balance, description, is_active`

This must match the seed CSV column order exactly (round-trip contract).
