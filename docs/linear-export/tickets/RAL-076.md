## Screen 15: AIP List (`/budget-planning/aip`)

### Filter bar

* Search: filters on fiscal year
* Fiscal Year dropdown
* Status dropdown: All / Draft / Final / Archived
* Entry Source dropdown: All / Upload / Manual

### Data table columns

`Fiscal Year · Source · Status · Offices · LDIP Ref · Uploaded By · Uploaded At · Actions`

### Actions

* **View**: opens read-only AIP detail
* **Edit** (Draft only)
* **WFP**: navigates to WFP page for this AIP

### "New AIP" button → `/budget-planning/aip/new`

## Screen 16: AIP Upload (`/budget-planning/aip/new`)

### Entry mode toggle (tabs)

* **Upload File** (default): drop zone for .xlsm
* **Manual Entry**: deprioritized — disabled placeholder tab for now (manual entry will be revisited later; see [RAL-62](<https://linear.app/ralphoksiprojects/issue/RAL-62/ui-aip-entry-form-createedit>))

### Fields (both modes)

* **Fiscal Year** (required, number)
* **Link to LDIP** (optional — select from Final LDIP records)

### Upload tab

* Drag-and-drop zone accepting `.xlsm` files up to 20 MB
* Browse button
* On file select: enable "Upload & Preview" button
* On submit: `POST /api/budget-planning/aip/upload` → navigates to Import Summary with preview data

---

## Screen 17: AIP Import Summary (`/budget-planning/aip/import-preview`)

Shown after upload, **before** confirming import.

### Summary counts banner

4 stat tiles: **Offices · Programs · Projects · Activities** (real file ≈ 2,309 activities — the mockup's 389 is sample data)

### Sector preview

Grouped list by sector (General `1xxx` / Social `3xxx` / Economic `8xxx` / Others `9xxx`) showing program and activity counts per sector. Display order: General → Social → Economic → Others.

### Warnings panel

Any data issues detected during parse (e.g. unresolved office names like "Janaury") are shown here before confirming.

### Actions

* **Confirm Import** → `POST /api/budget-planning/aip/confirm` → redirects to AIP detail
* **Cancel** → discards the upload, back to list

## Acceptance Criteria

- [ ] List filters work independently and in combination
- [ ] Upload accepts only .xlsm; rejects other file types with a clear message
- [ ] File size limit enforced (20 MB max) with user-friendly error
- [ ] Import summary shows accurate counts grouped by sector
- [ ] Warnings panel surfaces all skipped/unresolved rows before confirming
- [ ] Confirm Import writes to all 4 AIP tables (aip_offices, aip_programs, aip_projects, aip_activities)
- [ ] WFP action on list row navigates to `/budget-planning/wfp?aipId=&officeId=`
