## Why

`docs/Performance_Audit_2026-07-16.md` §1 found two related anti-patterns, both Medium severity but compounding over time:

* `AipService.cs:229-231`, `WfpReportService.cs:126-130`, `LdipService.cs:103-104, 564-565` — full-scan-for-sequence patterns, bounded by fiscal-year count today but will grow as years accumulate.
* `AipService.cs:63-64` — loads the **entire** `users` **table** for a name lookup, exactly the pattern `docs/PERFORMANCE_GUIDELINES.md` calls out by name ("not a dictionary built from the whole users table").
