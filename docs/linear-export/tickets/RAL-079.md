# RAL-79 — Report: WFP report generation (Excel export from template)

> 🌿 **Working branch:** `release/1.1.0` — all v1.1 work branches off `release/1.1.0` and PRs target `release/1.1.0` (not `main`).

## Overview

Generate the WFP report as an Excel export from a saved WFP record. Part of the v1.1 priority scope: Config pages → AIP upload → WFP page + **report**.

## Status: ⏸️ Awaiting template

**Ralph will share the Excel file that will be used as the template for report generation.** Scope, layout, and the Claude Code prompt will be defined after the template is reviewed (in Claude Code).

## Known context (to be confirmed against the template)

* Source data: `wfp_records` → `wfp_activities` → `wfp_expenditure_lines` (see `docs/v1.1/DB_Model.md` section 4)
* The existing WFP Excel file format: one office per sheet, expenditure lines grouped under PS / MOOE / CO with quarterly columns, 10% reserve, net appropriation (see `docs/v1.1/AIP_WFP_Import_Findings.md` §2 column map)
* The requirements doc notes the WFP feeds **LBP Form No. 2** (Programmed Appropriation by Object of Expenditure) and an **LBP Form No. 4** view (`docs/v1.1/LDIP_AIP_WFP_Web_Requirements.md` §7, §10) — confirm whether either/both are in scope
* Excel generation uses **ClosedXML**, same as the existing PR Report export ([RAL-50](<https://linear.app/ralphoksiprojects/issue/RAL-50/pr-report-report-endpoint-excel-export-closedxml>) / ExcelService pattern from [RAL-46](<https://linear.app/ralphoksiprojects/issue/RAL-46/excelservice-generateprtemplate-exportprreport-parseprimport-closedxml>))
* Likely trigger: an "Export" button on the WFP page ([RAL-68](<https://linear.app/ralphoksiprojects/issue/RAL-68/ui-wfp-budget-planning-page-hierarchical-activity-grid>)) and/or the AIP/WFP list
