# RAL-34 — Resource Links — domain model + migration + seed data

Add `ResourceLink` entity to Domain layer, create EF Core migration, and seed default links from the current PPDO Google Site structure.

> ⚠️ **Phase 1 issue — must be done before any Application services are built.** Adds `CanManageResourceLinks` to `PermissionGroup` which changes the DB schema.

**Domain entity:** `PPDO.Domain/Entities/ResourceLink.cs`
Fields: Id, Title, Url, Category, CategoryOrder, LinkOrder, IsActive, IsAdminCreated, SubmittedById (FK → User), CreatedAt, UpdatedAt

**PermissionGroup update:** Add `CanManageResourceLinks bool` to `PermissionGroup` entity and update seed migration.

**Migration:** `AddResourceLinks`

**Seed data:** 23 default links across 5 categories as defined in `CLAUDE.md` → Resource Links Seed Data section. All seeded with `IsAdminCreated = true`. URLs are placeholders — update with real Google Drive URLs before first deploy.

**Reference:** `CLAUDE.md` → Resource Links Seed Data, `PROJECT_DOCUMENTATION_NET_AZURE.md` → ResourceLink domain model
