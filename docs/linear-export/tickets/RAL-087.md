# RAL-87 — Public landing page: display published announcements

## Context

Part of v1.1.1 — Public Announcements feature. [RAL-83](https://linear.app/ralphoksiprojects/issue/RAL-83/db-api-announcements-entity-crud-html-sanitization) built the `GET /api/announcements` public endpoint. This ticket replaces the existing placeholder in the public landing page with a live announcements feed.

See full spec: `docs/v1.1.1/v1.1.1_Requirements.md` §3D.

> 🌿 **Working branch:** create feature branch off `hotfix/1.1.1` — PR targets `hotfix/1.1.1`
> **Blocked by: **[RAL-83](https://linear.app/ralphoksiprojects/issue/RAL-83/db-api-announcements-entity-crud-html-sanitization) (`GET /api/announcements` endpoint must exist)

## Scope

### `(public)/page.tsx` change

Extract the inline announcements block into a new client component `AnnouncementsSection.tsx`. Replace the inline JSX with `<AnnouncementsSection />`.

### New component: `src/components/landing/AnnouncementsSection.tsx`

This is a `"use client"` component (data fetch on mount, no auth).

**Data fetching:**

```ts
// No Authorization header — public endpoint
const res = await axios.get(`${process.env.NEXT_PUBLIC_API_BASE_URL}/announcements`);
```

**Loading state:** show a simple skeleton (3 grey bars) while fetching.

**Empty state:** keep the existing empty state card exactly as-is:

```tsx
<div className="bg-white rounded-lg border border-slate-200 px-8 py-14 text-center">
  <MegaphoneIcon />
  <p>No announcements yet</p>
  <p>Check back later for updates from the office.</p>
</div>
```

**Announcement card (one per published announcement):**

```
┌──────────────────────────────────────────┐
│ Title                              Jun 18 │
│ ─────────────────────────────────────── │
│ [Rich text content rendered here]        │
└──────────────────────────────────────────┘
```

* White background, `border border-slate-200`, no rounded corners (flat design)
* Title: `text-lg font-semibold text-slate-800`
* Date: `text-sm text-slate-400` (right-aligned, formatted as "MMM D, YYYY")
* Content: rendered via `dangerouslySetInnerHTML={{ __html: DOMPurify.sanitize(item.content) }}`
* `DOMPurify` import: `import DOMPurify from 'dompurify'` (client-side only — already safe since this is a `"use client"` component)
* Cards stacked vertically with `gap-4`

**Error state:** on fetch failure, silently show the empty state (don't break the page).

### Add public announcement type

ADD `AnnouncementPublic { id, title, content, publishedAt }` to `src/types/announcements.ts` (or create the file if [RAL-86](https://linear.app/ralphoksiprojects/issue/RAL-86/admin-portal-announcements-management-page-tiptap-rich-text-editor) hasn't run yet — keep it compatible).
