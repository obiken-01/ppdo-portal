# RAL-24 — Scaffold .NET solution structure (5 projects)

Create the .NET solution with 5 projects following Clean Architecture:

* `PPDO.Domain` — Entities, Interfaces, Enums
* `PPDO.Infrastructure` — AppDbContext, Repositories, Services
* `PPDO.Application` — Services, DTOs, Validators
* `PPDO.Functions` — Azure Functions HTTP triggers
* `PPDO.Tests` — xUnit + Moq test project

**Reference:** `CLAUDE.md` → Repository Structure, Code Delivery Order
**Conventions:** `NAMING_CONVENTIONS.md` → C# / .NET section

```
dotnet new sln -n PPDO
dotnet new classlib -n PPDO.Domain
dotnet new classlib -n PPDO.Infrastructure
dotnet new classlib -n PPDO.Application
dotnet new func -n PPDO.Functions --worker-runtime dotnetIsolated
dotnet new xunit -n PPDO.Tests
```
