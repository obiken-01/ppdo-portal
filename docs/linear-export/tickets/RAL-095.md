# RAL-95 — UX: clamp long WFP names to 2 lines (program / project / activity rows)

## Context

In the WFP grid, the name column is unbounded. Source AIP data sometimes packs a very long descriptor into a single activity name (e.g. an entire staffing roster: "Manpower augmentation through creation of additional permanent positions: ADMINISTRATIVE DIVISION Administrative Officer V - SG 18 …"), which makes one row grow to ~600px tall and pushes every other row off-screen — defeating the point of a scannable grid.

> 🌿 **Working branch:** create feature branch off `hotfix/1.1.1` — PR targets `hotfix/1.1.1` (NOT main)

### Decision (UX consult, 2026-06-22)

Clamp the name cell to **2 lines with ellipsis** so every row is a predictable height, and reveal the full text on demand. We are NOT making the whole row a click target (accessibility burden + redundant with the existing Edit button); the existing Edit → expenditure popup is the reveal path. Apply the same clamp to **program and project** name rows, not just activities — they have the same unbounded-name risk.

### Current code

`frontend/src/app/(portal)/budget-planning/wfp/page.tsx`:

* Activity name cell (`:1197`): `<td className="px-3 py-2 pl-14 text-slate-700">{activity.name}</td>` — no clamp (the main offender).
* Project name cell (`:1176`): `{project.name}` — unbounded.
* Program name cell (`:1152`): `{program.name}` — unbounded.
* Expenditure popup header (`:307`): `<div className="text-base font-semibold text-slate-800 truncate max-w-2xl">{activity.name}</div>` — single-line `truncate`, so the full name is currently NOT fully visible anywhere.

---

## Frontend only — no backend change

1. **Clamp the name cells** for program (`:1152`), project (`:1176`), and activity (`:1197`) to 2 lines: wrap each name in a `div` with `line-clamp-2` (`display:-webkit-box; -webkit-line-clamp:2; -webkit-box-orient:vertical; overflow:hidden`) so row height is uniform. Keep the ref code, fund source, budget, and quarterly columns as-is. (If Tailwind's `line-clamp-2` utility is available in the config, use it; otherwise the inline style above.)
2. **Reveal full text in the popup**: change the expenditure popup header (`:307`) from single-line `truncate max-w-2xl` to show the **full, wrapping** activity name (no clamp/truncate) — this becomes the canonical place to read the whole thing. The Edit button already opens this popup, so no new affordance is needed.
3. **Tooltip bonus**: add a `title={name}` attribute on each clamped cell so hovering shows the full text on desktop (cheap, no layout cost). Not a replacement for the popup — just a quick peek.

> ⚠️ Keep it accessible: do NOT convert the row into a `div onClick` handler. The existing Edit `<button>` stays as the action; the clamp is display-only.

## Acceptance Criteria

- [ ] Program, project, and activity name cells clamp to 2 lines with ellipsis — no row exceeds ~2 lines of name height
- [ ] Rows are uniform height regardless of name length; the grid stays scannable
- [ ] Opening a long activity's expenditure popup shows the complete name (wrapped, untruncated) in the header
- [ ] Hovering a clamped name shows the full text via the native `title` tooltip
- [ ] No change to ref code / fund / budget / quarterly columns, the Edit action, or any data; tsc + `npm run build` pass
