# RAL-97 — Divisions + permission-model rebuild (retire PermissionGroup/Division enum/Observer)

Foundation ticket for v1.2. Replaces the v1.1 permission model with one configurable per-office `divisions` table that carries BOTH data scope and feature flags. Retires `PermissionGroup`, the `Division` enum, and the `Observer` role; aligns inventory to `division_id` on a clean slate.

> 🌿 **Working branch:** create `feature/v1.2-ral-97-divisions-permission-core` off `release/1.2.0` — PR targets `release/1.2.0` (**NOT main**).
