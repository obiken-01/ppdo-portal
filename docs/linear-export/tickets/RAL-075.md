## Screen 13: LDIP List (`/budget-planning/ldip`)

### Filter bar

* Search: filters on `title` or `ref_code`
* Status dropdown: All / Draft / Final / Archived
* Entry Mode dropdown: All / New / Amendment / Supplemental

### Data table columns

`Ref Code · Title · Period · Entry Mode · Status · Created · Actions`

* **Status**: Draft / Final / Archived badge
* **Actions**: Edit (Draft only) · View

### Behaviour

* Clicking a row opens the detail/edit form (Draft) or read-only view (Final/Archived)
* "New LDIP" button → navigates to entry form

---

## Screen 14: LDIP Entry Form (`/budget-planning/ldip/new` or `/budget-planning/ldip/:id/edit`)

### Fields

1. **Title** (required, text input)
2. **Entry Mode** (required, select: New / Amendment / Supplemental)
3. **Fiscal Year Start** (required, number, e.g. 2027)
4. **Fiscal Year End** (required, number, e.g. 2029)
5. **Source LDIP** (required when Entry Mode ≠ New — select from existing Final LDIPs)

### Status behaviour — Draft / Final / Archived

* New records are created as `Draft` (editable)
* **Finalize** button: Draft → Final (locked, read-only) — confirm dialog before finalizing
* Once Final, edits require an admin unlock (Final → Draft)
* When an Amendment/Supplemental is finalized, the source record becomes `Archived`
* See `docs/v1.1/DB_Model.md` note 9 / note 11
* ⚠️ The Screen 14 mockup shows "Submit for Approval" / "route for approval" — that copy is **stale**; there is no approval step. Use **Finalize** (Draft → Final).

### Buttons

* Save Draft · Finalize · Cancel
