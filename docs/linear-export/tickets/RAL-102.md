# RAL-102 — WFP division scoping — per-division records, filter, division-budget validation, setup gate

Make WFP division-aware: per-division records (kills the full-replace data-loss bug), server-side division filter, gross-total division-budget validation, and the setup-complete gate. Depends on [RAL-97](https://linear.app/ralphoksiprojects/issue/RAL-97/divisions-permission-model-rebuild-retire-permissiongroupdivision) (divisions), [RAL-99](https://linear.app/ralphoksiprojects/issue/RAL-99/allocation-backend-ceiling-division-allocation-ppa-assignment) (allocation service: setup-status + allocation lookups), [RAL-100](https://linear.app/ralphoksiprojects/issue/RAL-100/shared-moneyinput-component-peso-prefix-comma-formatting) (MoneyInput).
