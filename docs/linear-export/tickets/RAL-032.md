# RAL-32 — Set up Azure Application Insights + wire into Functions host

Set up Azure Application Insights and wire it into the Azure Functions host via `Program.cs`.

**Steps:**

**1. Create Application Insights resource in Azure Portal**

* Resource group: `ppdo-portal-rg`
* Name: `ppdo-portal-insights`
* Region: Southeast Asia
* Resource Mode: Workspace-based
* After creation → Overview → copy the **Connection String**

**2. Install NuGet package in PPDO.Functions**

```bash
dotnet add package Microsoft.ApplicationInsights.WorkerService
```

**3. Register in Program.cs**

```csharp
builder.Services.AddApplicationInsightsTelemetryWorkerService();
```

**4. Add to local.settings.json**

```json
"APPLICATIONINSIGHTS_CONNECTION_STRING": ""
```

Leave blank locally — console logging still works via `ILogger<T>`.

**5. Add to Azure App Settings**
Add `APPLICATIONINSIGHTS_CONNECTION_STRING` with the real connection string.

**6. Verify**

* `func start` locally — no errors
* Deploy to Azure → check Application Insights → Live Metrics

**Reference:** `CLAUDE.md` → Logging section
`PROJECT_DOCUMENTATION_NET_AZURE.md` → Section 9, Section 12 Step 3b
