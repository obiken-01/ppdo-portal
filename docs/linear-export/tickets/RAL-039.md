# RAL-39 — Auth — JWT login, refresh, logout + AuthService

Implement AuthService and AuthFunctions for login, token refresh, logout, and current user.

**AuthService methods:**

* `LoginAsync(email, password)` → validates credentials, returns AccessToken (15 min JWT) + RefreshToken (7 days, stored in DB)
* `RefreshAsync(refreshToken)` → validates refresh token, rotates tokens
* `LogoutAsync(refreshToken)` → revokes refresh token in DB
* `GetCurrentUserAsync(userId)` → returns user info + effective permissions

**AuthFunctions endpoints:**

* `POST /api/auth/login` — public
* `POST /api/auth/refresh` — public
* `POST /api/auth/logout` — protected
* `GET /api/auth/me` — protected, returns role + division + effective permission flags

**JWT claims to include:** UserId, Role, Division, Email

**Reference:** `PROJECT_DOCUMENTATION_NET_AZURE.md` → Section 7 (Auth flow), API endpoints
