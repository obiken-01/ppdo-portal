# RAL-37 — Infrastructure — generic Repository + feature repositories

Implement generic and feature-specific repositories in `PPDO.Infrastructure`. This must be done before any Application services are built.

**Generic repository:** `IRepository<T>` implementation with: `GetByIdAsync`, `GetAllAsync`, `AddAsync`, `UpdateAsync`, `DeleteAsync`, `SaveChangesAsync`

**Feature repositories:**

* `PurchaseRequestRepository` — includes PRItems, GetByDivision scoping
* `ItemMasterRepository` — lookup by StockNo, by Description (for autocomplete)
* `DeliveryRepository` — includes DeliveryItems + Distributions
* `UserRepository` — GetByEmail, GetWithGroup
* `ResourceLinkRepository` — GetAllGrouped by category

**Reference:** `PROJECT_DOCUMENTATION_NET_AZURE.md` → Architecture, Domain Models
