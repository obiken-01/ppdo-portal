# RAL-189 — Replace placeholder logo with official PPDO logo (public site, login, portal navbar)

## Context

Ralph provided the official PPDO logo (2026-07-29), located locally at
`D:\RalphFiles\PPDO\PPDO\ppdo_logo\` — three files, all the same circular badge
design (green ring, gear motif, four-quadrant icon grid — location pin, magnifying
glass/growth chart, lightbulb, hands holding a heart), transparent background:

* `ppdo_logo.svg` (742 KB — almost certainly embedded raster textures, not clean
  vector paths, given the file size for this style of illustration)
* `ppdo_logo.png` (2048×2048, RGBA, 701 KB)
* `ppdo_logo_1024.png` (1024×1024, RGBA, 329 KB)

CLAUDE.md's own landing-page spec anticipated this exact moment: "PPDO logo:
`public/images/ppdo-logo-placeholder.png` — generate a simple green circle
placeholder (**replaced when official logo is provided**)."

## Picked asset & strategy

* **Source**: `ppdo_logo_1024.png`. Plenty of resolution — no need for the 2048px
  version or the SVG.
* **Largest on-screen size** across every current usage is 88px (login page desktop
  branding panel) → 176px at 2x pixel density. Downscale the source to **256×256**
  (comfortable 2x headroom), export as an optimized PNG + WebP pair. Current
  placeholder files are ~2 KB each — this must land in the same range, not regress
  toward hundreds of KB. [RAL-91](https://linear.app/ralphoksiprojects/issue/RAL-91/perf-optimize-login-page-seallogo-pngs-184-kb-webpnext-image) is the precedent (compressed 184 KB of login-page
  images down to WebP for the same reason).
* **Replace in place** at the exact filenames already referenced in code — zero code
  changes required, matching CLAUDE.md's own "replaced" wording:
  * `frontend/public/images/ppdo-logo-placeholder.png`
  * `frontend/public/images/ppdo-logo-placeholder.webp`

## Touchpoints (already reference these exact filenames)

* `frontend/src/app/(public)/page.tsx:43` — public landing page header (56×56)
* `frontend/src/components/landing/Navbar.tsx:24` — public navbar (28×28)
* `frontend/src/app/(public)/login/page.tsx:133` — login page desktop branding panel (88×88)
* `frontend/src/app/(public)/login/page.tsx:186` — login page mobile logo (36×36)
* `frontend/src/components/layout/Sidebar.tsx:172` — portal sidebar/navbar (32×32)

## Optional bonus (not explicitly requested — confirm before doing)

`frontend/src/app/favicon.ico` currently holds a generic 16/32px icon, not the PPDO
logo. Regenerating it from the same source would make the browser tab icon match
too.

## Open question for Ralph

Keep the filenames as `ppdo-logo-placeholder.*` (zero code changes, matches
CLAUDE.md's existing wording) or rename to `ppdo-logo.*` now that it's official,
not a placeholder (touches all 5 code references + one CLAUDE.md doc line)?
**Recommendation: keep as-is** — pure cosmetic rename, no functional benefit, easy
to do later if it bothers anyone.

## Steps

1. Resize `ppdo_logo_1024.png` → 256×256, optimize (pngquant/oxipng or equivalent).
2. Export a WebP encode at the same dimensions, similarly compressed.
3. Overwrite `frontend/public/images/ppdo-logo-placeholder.png` and `.webp` in place.
4. (If approved) regenerate `frontend/src/app/favicon.ico` from the same source.
5. Live-verify all 5 render locations at their real display sizes — public landing
   page, public navbar, login page (desktop + mobile viewport), portal sidebar.

## Out of scope

* Renaming the asset files / updating the 5 code references (see open question

* Any other branding asset (letterhead, a full favicon multi-size set, social share
  images) — logo only, per this ticket's ask.
