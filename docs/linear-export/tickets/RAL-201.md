# RAL-201 — Mobile layout fixes across Configuration pages

On narrow/mobile viewports, all Configuration pages (Accounts, Offices, Divisions, Funding Sources, Procurement Presets, Price Index) squeeze badly:

1. **Header row** — title/description block and the action-button row (Export CSV / Upload CSV / Add X) share one non-wrapping flex row (`flex items-start justify-between gap-3`), so on narrow screens the description text gets crushed into a tiny column while the buttons stay full-width.
2. **Table columns** — `DataTable` (shared across all config pages) has no `min-width` on its `<table>`, so `overflow-x-auto` never actually engages; columns just squish instead of triggering horizontal scroll. Divisions (13 columns) and Price Index (9 columns) are the worst hit.
3. **Action-column buttons** — "Edit · Deactivate/Reactivate" text-link pairs in the rightmost column wrap/crush along with everything else once columns start squishing.

## Fix

* Extract a shared `ConfigPageHeader` component (title, description, action buttons as children) that stacks title above buttons below the `sm` breakpoint instead of forcing one row.
* Add a `minWidth` prop to the shared `DataTable` component, applied via inline style to the `<table>` so `overflow-x-auto` triggers correctly — same pattern already used ad hoc in the Inventory pages (`min-w-[Npx]` tuned per column count).
* Swap all Config pages onto both.
* Actions-column squish (#3) should resolve automatically once the table can scroll horizontally instead of collapsing.
