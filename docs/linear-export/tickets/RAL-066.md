# RAL-66 — Epic: Configuration Management — Accounts, Offices, Funding Sources

## Overview

Encompasses all work to build the **Configuration Management** section of the PPDO Portal — the shared backend tables, API endpoints, and UI pages for managing Accounts, Offices, and Funding Sources.

## Why This Is Needed

WFP expenditure entry requires:

* Account codes/titles for the Object of Expenditure dropdown (143 PS/MOOE/CO expense accounts)
* Office list for office selection and scoping
* Funding Sources for the Source of Fund dropdown

These must be admin-configurable (not hardcoded) so PPDO staff can add/update entries without code changes.

## Scope

1. **DB**: Config tables (`ChartOfAccounts`, `PlanningOffices`, `FundingSources`) with seed data
2. **API**: CRUD endpoints + CSV upload/download for each config type
3. **UI**: Config Dashboard + 3 config pages (Accounts, Offices, Funding Sources)

* `AIP/chart_of_accounts.csv` — 143 PS/MOOE/CO expense accounts
* `AIP/offices.csv` — 16 offices
* `AIP/funding_sources.csv` — 6 sources (GF, GAD, LDRRMF, SEF, 20DF, TF)
