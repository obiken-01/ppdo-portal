# RAL-27 — Set up EF Core AppDbContext + initial migration

Set up EF Core in `PPDO.Infrastructure` — AppDbContext, all entity configurations, and the initial migration.

**Steps:**

1. Install packages: `Microsoft.EntityFrameworkCore.SqlServer`, `Microsoft.EntityFrameworkCore.Tools`, `Microsoft.EntityFrameworkCore.Design`
2. Create `AppDbContext.cs` — DbSets for all entities, model configurations
3. Configure entity relationships (FK constraints, indexes)
4. Add initial migration: `dotnet ef migrations add InitialCreate`
5. Apply to local SQL Server Express: `dotnet ef database update`

**Local connection string (SQL Server Express — Windows Auth):**

```
Server=.\SQLEXPRESS;Database=PPDOPortalDev;Trusted_Connection=True;TrustServerCertificate=True;
```

**Database naming conventions** (`NAMING_CONVENTIONS.md`):

* Table names: PascalCase matching entity (e.g. `PurchaseRequests`, `PRItems`)
* Column names: PascalCase matching property
* FK convention: `[EntityName]Id`
* Index convention: `IX_[Table]_[Column]`

**Reference:** `PROJECT_DOCUMENTATION_NET_AZURE.md` → Section 5 (Domain Models), Section 8 (Infrastructure)
