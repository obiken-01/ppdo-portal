Project picker — the editor's selector row

Fiscal year → (Office) → Program → Project. Both pickers are searchable lookups fed by one call, GET /proposals/projects, for the chosen office and year. Every project shows its proposal status.
1 · Project lookup, open
Lists only the chosen program's projects, in ref-code order. The current one is ticked. Choosing another moves straight to its proposal.
Type to filter by code or name. ↑/↓ and Enter work as in every portal Lookup.
2 · Program lookup, searching
Each program shows how far along its proposals are. Changing program clears the project until one is picked.
Fiscal year lists FY 2028 onward only; proposals do not exist for FY 2027.
3 · PPDO caller who sees several offices
An Office picker appears first. Program and Project wait for it, because the list is one office at a time. Guest-office users never see this picker; they are pinned to their own office.
4 · A project with no proposal
The sections are replaced by a Create panel. The left rail stays hidden until there is a proposal to move through.
This project has no investment proposal yet.
Creating one fills in the description, the general objective and the activity names from the AIP, and the signatories from the province's defaults.
Open in AIP Entry ↗
5 · Switching project with unsaved sections
The same three-button guard as leaving a section. It applies to Fiscal year, Office and Program changes too, because each one leaves the current proposal.
Save your changes first?
Two sections have unsaved changes: G · Work Plan and I · Implementing Team. Opening 002 — Corn Productivity Enhancement leaves this proposal.
6 · Edge states
What the pickers show when there is nothing, or nothing you may create.
No projects for this office and year
Project lookup empty state: "No FY 2028 projects in this office yet." with Add them in AIP Entry ↗.
Cross-office reviewer
Same pickers and statuses. A None project shows "No proposal yet. Only the office can create one." with no Create button; Draft and Final open read-only.
Loading and errors
While the list loads, the lookups show a skeleton option list and stay usable once it lands. On error the picker shows "Couldn't load the projects." with Retry. The open proposal is not affected.
Opened from a link
?projectId= preselects the program and project: Create panel if None, else the proposal. ?id= opens the proposal and fills the pickers from it.
